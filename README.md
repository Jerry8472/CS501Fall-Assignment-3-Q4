## How to use the app
Clone the repo, open it in Android Studio, and press Run to launch on an emulator or device.

## Explanation
App demonstrates how to use Scaffold in Jetpack Compose to structure a layout with a top app bar, bottom navigation bar, and a floating action button.
- TopAppBar: Displays the app title.
- Bottom Navigation Bar: Includes three items - Home, Settings, Profile.
- Floating Action Button: Shows a Snackbar with the message "FAB clicked" when pressed.
- Inner Padding: Properly applied so the content ("Hello" text) avoids overlap with the top bar, bottom bar, and FAB.
